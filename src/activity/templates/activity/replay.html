Circuit Replay Methods
Data scope
  • Graph metrics are computed on the full connectome graph for each connectome dataset, not only visible neurons.
  • Behavior correlations are computed per activity dataset.
Degree metrics
  • degree_in_full: sum of incoming synapse counts over the full connectome.
  • degree_out_full: sum of outgoing synapse counts over the full connectome.
  • degree_total_full: degree_in_full + degree_out_full.
  • Electrical synapses are treated as bidirectional for replay flow and degree calculations.
PageRank centrality
  • Computed on a weighted directed graph using synapse counts as edge weights.
  • Higher values indicate nodes that receive influence from important upstream nodes.
Eigenvector centrality
  • Computed on a weighted undirected projection of the full connectome.
  • Higher values indicate nodes connected to other highly central nodes.
Behavior correlation
  • For each behavior trace, correlation is Pearson correlation between normalized neuron activity and behavior over overlapping time points.
  • A separate node feature is available for each behavior key in the dataset.
  • Positive values indicate aligned trends; negative values indicate anti-aligned trends.
