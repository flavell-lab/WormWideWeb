You can download complete paper archives as JSON or go to each paper repository for full HDF5 bundles.

HDF5 vs JSON

HDF5 Repository Bundles

The repository bundle (processed_h5.tar.bz2) is the full processed source package used by the project pipeline.

  • Includes the full per-animal HDF5 datasets.
  • Includes behavior and analysis data not included in website JSON exports.
  • For papers with NeuroPAL label or encoding data, there're extra artfifacts available.
  • θh_pos_is_ventral sign correction must be applied per dataset for head-angle-related behavior traces.
JSON Archive Bundles

The JSON archive is a web-focused export used by WormWideWeb pages and APIs.

  • Includes all essential behavior and neural time series and timing info.
  • Includes metadata checksums and optional NeuroPAL labels and/or encoding data if available.
  • Omits source fields that are not used in the current web app.
  • JSON field-level details: dataset_json_readme.md
  • θh_pos_is_ventral correction is already applied.

Notes

General

  • Use HDF5 repository bundles when you need full source coverage and project-internal fields.
  • Use JSON archives when you want direct compatibility with WormWideWeb analysis and visualization flows.
  • Per-dataset JSON downloads are also available from the Neural Activity pages.

θh_pos_is_ventral Correction

  • Use this flag to set the correct sign convention for head-angle-related behaviors (for example, head angle and angular velocity).
  • For raw HDF5 workflows, apply correction per dataset: dv_correction = θh_pos_is_ventral ? -1 : 1.
  • For WormWideWeb JSON archives, this correction is already applied.
  • The per-dataset flag is listed in each paper manifest CSV in this repository.

Neural traces

  • trace_original: raw neural activity traces from each neuron (unscaled source signal)
  • trace_array: z-scored neural activity traces derived from trace_original (standardized per neuron)
  • trace_array_F20: neural traces normalized by each neuron's 20th percentile of raw activity (F20 baseline)
  • trace_array_Fmean: neural traces normalized by each neuron's mean raw activity (Fmean baseline)
